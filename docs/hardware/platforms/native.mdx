# Native

**Registry:** [https://registry.platformio.org/platforms/platformio/native](https://registry.platformio.org/platforms/platformio/native)  
**Configuration:** [platform](../../reference/platformio-ini/env/platform.md) = `platformio/native`

Native development platform is intended to be used for desktop OS. This platform uses built-in toolchains (preferable based on GCC), frameworks, libs from particular OS where it will be run.

Vendor website: [registry.platformio.org](https://registry.platformio.org/platforms/platformio/native?utm_source=platformio.org&utm_medium=docs).

## Stable and upstream versions

Choose between the [stable releases](https://github.com/platformio/platform-native/releases) of the Native platform and its latest upstream version with the [platform](../../reference/platformio-ini/env/platform.md) option in [platformio.ini](../../reference/platformio-ini/index.md).

### Stable

```ini
; Latest stable version, NOT recommended
; Pin the version as shown below
[env:latest_stable]
platform = native

; Specific version
[env:custom_stable]
platform = native@x.y.z
```

### Upstream

```ini
[env:upstream_develop]
platform = https://github.com/platformio/platform-native.git
```
