# Energia

**Configuration:** [framework](../../reference/platformio-ini/env/framework.md) = `energia`

Energia Wiring-based Framework for Texas Instruments MSP430 microcontrollers

## Platforms

| Name | Description |
|---|---|
| [TI MSP430](../platforms/timsp430.md) | MSP430 microcontrollers (MCUs) from Texas Instruments (TI) are 16-bit, RISC-based, mixed-signal processors designed for ultra-low power. These MCUs offer the lowest power consumption and the perfect mix of integrated peripherals for thousands of applications. |
| [TI TIVA](../platforms/titiva.md) | Texas Instruments TM4C12x MCUs offer the industrys most popular ARM Cortex-M4 core with scalable memory and package options, unparalleled connectivity peripherals, advanced application functions, industry-leading analog integration, and extensive software solutions. |
