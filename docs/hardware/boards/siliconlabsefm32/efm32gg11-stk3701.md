# SLSTK3701A Giant Gecko S1

## Hardware

Platform [Silicon Labs EFM32](../../platforms/siliconlabsefm32.md): Silicon Labs EFM32 Gecko 32-bit microcontroller (MCU) family includes devices that offer flash memory configurations up to 256 kB, 32 kB of RAM and CPU speeds up to 48 MHz. Based on the powerful ARM Cortex-M core, the Gecko family features innovative low energy techniques, short wake-up time from energy saving modes and a wide selection of peripherals, making it ideal for battery operated applications and other systems requiring high performance and low-energy consumption.

| Specification | Value |
|---|---|
| **Microcontroller** | EFM32GG11B820F2048GL192 |
| **Frequency** | 48MHz |
| **Flash** | 2MB |
| **RAM** | 512KB |
| **Vendor** | [Silicon Labs](https://www.silabs.com/development-tools/mcu/32-bit/efm32gg11-starter-kit?utm_source=platformio.org&utm_medium=docs) |

## Configuration

Use the board ID `efm32gg11_stk3701` in the [board](../../../reference/platformio-ini/env/board.md) option of [platformio.ini](../../../reference/platformio-ini/index.md):

```ini
[env:efm32gg11_stk3701]
platform = siliconlabsefm32
board = efm32gg11_stk3701
```

To override a setting of the board manifest [efm32gg11_stk3701.json](https://github.com/platformio/platform-siliconlabsefm32/blob/master/boards/efm32gg11_stk3701.json) in a project environment, use an option named `board_` followed by the setting's JSON path, for example `board_build.mcu` or `board_build.f_cpu`:

```ini
[env:efm32gg11_stk3701]
platform = siliconlabsefm32
board = efm32gg11_stk3701

; change microcontroller
board_build.mcu = efm32gg11b820f2048gl192

; change MCU frequency
board_build.f_cpu = 48000000L
```

## Uploading

SLSTK3701A Giant Gecko S1 supports these upload protocols:

- `blackmagic`
- `jlink`
- `mbed`

The default is `mbed`.

To use another one, set the [upload_protocol](../../../reference/platformio-ini/env/upload-protocol.md) option:

```ini
[env:efm32gg11_stk3701]
platform = siliconlabsefm32
board = efm32gg11_stk3701

upload_protocol = mbed
```

## Debugging

The SLSTK3701A Giant Gecko S1 has an on-board debug probe: [Debugging](../../../guides/debugging/index.md) works without extra hardware.

Select the probe with the [debug_tool](../../../reference/platformio-ini/env/debug-tool.md) option in [platformio.ini](../../../reference/platformio-ini/index.md). If you do not set it, the probe marked as default is used.

:::warning

Most debug probes need a driver or udev rules. See the probe's page for instructions.

:::
