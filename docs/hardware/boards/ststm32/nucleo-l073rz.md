# ST Nucleo L073RZ

## Hardware

Platform [ST STM32](../../platforms/ststm32.mdx): The STM32 family of 32-bit Flash MCUs based on the ARM Cortex-M processor is designed to offer new degrees of freedom to MCU users. It offers a 32-bit product range that combines very high performance, real-time capabilities, digital signal processing, and low-power, low-voltage operation, while maintaining full integration and ease of development.

| Specification | Value |
|---|---|
| **Microcontroller** | STM32L073RZ |
| **Frequency** | 32MHz |
| **Flash** | 192KB |
| **RAM** | 20KB |
| **Vendor** | [ST](https://developer.mbed.org/platforms/ST-Nucleo-L073RZ/?utm_source=platformio.org&utm_medium=docs) |

## Configuration

Please use `nucleo_l073rz` ID for [board](../../../reference/platformio-ini/env/board.md) option in ["platformio.ini" (Project Configuration File)](../../../reference/platformio-ini/index.md):

```ini
[env:nucleo_l073rz]
platform = ststm32
board = nucleo_l073rz
```

You can override default ST Nucleo L073RZ settings per build environment using `board_***` option, where `***` is a JSON object path from board manifest [nucleo_l073rz.json](https://github.com/platformio/platform-ststm32/blob/master/boards/nucleo_l073rz.json). For example, `board_build.mcu`, `board_build.f_cpu`, etc.

```ini
[env:nucleo_l073rz]
platform = ststm32
board = nucleo_l073rz

; change microcontroller
board_build.mcu = stm32l073rz

; change MCU frequency
board_build.f_cpu = 32000000L
```

## Uploading

ST Nucleo L073RZ supports the following uploading protocols:

- `blackmagic`
- `cmsis-dap`
- `jlink`
- `mbed`
- `stlink`

Default protocol is `stlink`

You can change upload protocol using [upload_protocol](../../../reference/platformio-ini/env/upload-protocol.md) option:

```ini
[env:nucleo_l073rz]
platform = ststm32
board = nucleo_l073rz

upload_protocol = stlink
```
