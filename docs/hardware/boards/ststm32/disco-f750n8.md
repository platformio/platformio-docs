# STM32F7508-DK

## Hardware

Platform [ST STM32](../../platforms/ststm32.mdx): The STM32 family of 32-bit Flash MCUs based on the ARM Cortex-M processor is designed to offer new degrees of freedom to MCU users. It offers a 32-bit product range that combines very high performance, real-time capabilities, digital signal processing, and low-power, low-voltage operation, while maintaining full integration and ease of development.

| Specification | Value |
|---|---|
| **Microcontroller** | STM32F750N8H6 |
| **Frequency** | 216MHz |
| **Flash** | 64KB |
| **RAM** | 340KB |
| **Vendor** | [ST](https://www.st.com/content/st_com/en/products/evaluation-tools/product-evaluation-tools/mcu-mpu-eval-tools/stm32-mcu-mpu-eval-tools/stm32-discovery-kits/stm32f7508-dk.html?utm_source=platformio.org&utm_medium=docs) |

## Configuration

Please use `disco_f750n8` ID for [board](../../../reference/platformio-ini/env/board.md) option in ["platformio.ini" (Project Configuration File)](../../../reference/platformio-ini/index.md):

```ini
[env:disco_f750n8]
platform = ststm32
board = disco_f750n8
```

You can override default STM32F7508-DK settings per build environment using `board_***` option, where `***` is a JSON object path from board manifest [disco_f750n8.json](https://github.com/platformio/platform-ststm32/blob/master/boards/disco_f750n8.json). For example, `board_build.mcu`, `board_build.f_cpu`, etc.

```ini
[env:disco_f750n8]
platform = ststm32
board = disco_f750n8

; change microcontroller
board_build.mcu = stm32f750n8h6

; change MCU frequency
board_build.f_cpu = 216000000L
```

## Uploading

STM32F7508-DK supports the following uploading protocols:

- `blackmagic`
- `cmsis-dap`
- `jlink`
- `stlink`

Default protocol is `stlink`

You can change upload protocol using [upload_protocol](../../../reference/platformio-ini/env/upload-protocol.md) option:

```ini
[env:disco_f750n8]
platform = ststm32
board = disco_f750n8

upload_protocol = stlink
```

STM32F7508-DK has on-board debug probe and **IS READY** for debugging. You don't need to use/buy external debug probe.
