# 96Boards B96B-F446VE

## Hardware

Platform [ST STM32](../../platforms/ststm32.mdx): The STM32 family of 32-bit Flash MCUs based on the ARM Cortex-M processor is designed to offer new degrees of freedom to MCU users. It offers a 32-bit product range that combines very high performance, real-time capabilities, digital signal processing, and low-power, low-voltage operation, while maintaining full integration and ease of development.

| Specification | Value |
|---|---|
| **Microcontroller** | STM32F446VET6 |
| **Frequency** | 168MHz |
| **Flash** | 512KB |
| **RAM** | 128KB |
| **Vendor** | [96Boards](https://developer.mbed.org/platforms/ST-B96B-F446VE/?utm_source=platformio.org&utm_medium=docs) |

## Configuration

Use the board ID `b96b_f446ve` in the [board](../../../reference/platformio-ini/env/board.md) option of [platformio.ini](../../../reference/platformio-ini/index.md):

```ini
[env:b96b_f446ve]
platform = ststm32
board = b96b_f446ve
```

To override a setting of the board manifest [b96b_f446ve.json](https://github.com/platformio/platform-ststm32/blob/master/boards/b96b_f446ve.json) in a project environment, use an option named `board_` followed by the setting's JSON path, for example `board_build.mcu` or `board_build.f_cpu`:

```ini
[env:b96b_f446ve]
platform = ststm32
board = b96b_f446ve

; change microcontroller
board_build.mcu = stm32f446vet6

; change MCU frequency
board_build.f_cpu = 168000000L
```

## Uploading

96Boards B96B-F446VE supports these upload protocols:

- `blackmagic`
- `cmsis-dap`
- `jlink`
- `mbed`
- `stlink`

The default is `stlink`.

To use another one, set the [upload_protocol](../../../reference/platformio-ini/env/upload-protocol.md) option:

```ini
[env:b96b_f446ve]
platform = ststm32
board = b96b_f446ve

upload_protocol = stlink
```

## Debugging

The 96Boards B96B-F446VE has an on-board debug probe: [Debugging](../../../guides/debugging/index.md) works without extra hardware.

Select the probe with the [debug_tool](../../../reference/platformio-ini/env/debug-tool.md) option in [platformio.ini](../../../reference/platformio-ini/index.md). If you do not set it, the probe marked as default is used.

:::warning

Most debug probes need a driver or udev rules. See the probe's page for instructions.

:::
