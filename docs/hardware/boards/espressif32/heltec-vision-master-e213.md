# Heltec Vision Master E213

## Hardware

Platform [Espressif 32](../../platforms/espressif32.mdx): ESP32 is a series of low-cost, low-power system on a chip microcontrollers with integrated Wi-Fi and Bluetooth. ESP32 integrates an antenna switch, RF balun, power amplifier, low-noise receive amplifier, filters, and power management modules.

| Specification | Value |
|---|---|
| **Microcontroller** | ESP32S3 |
| **Frequency** | 240MHz |
| **Flash** | 8MB |
| **RAM** | 320KB |
| **Vendor** | [Heltec](https://heltec.org/project/vision-master-e213/?utm_source=platformio.org&utm_medium=docs) |

## Configuration

Please use `heltec_vision_master_e213` ID for [board](../../../reference/platformio-ini/env/board.md) option in ["platformio.ini" (Project Configuration File)](../../../reference/platformio-ini/index.md):

```ini
[env:heltec_vision_master_e213]
platform = espressif32
board = heltec_vision_master_e213
```

You can override default Heltec Vision Master E213 settings per build environment using `board_***` option, where `***` is a JSON object path from board manifest [heltec_vision_master_e213.json](https://github.com/platformio/platform-espressif32/blob/master/boards/heltec_vision_master_e213.json). For example, `board_build.mcu`, `board_build.f_cpu`, etc.

```ini
[env:heltec_vision_master_e213]
platform = espressif32
board = heltec_vision_master_e213

; change microcontroller
board_build.mcu = esp32s3

; change MCU frequency
board_build.f_cpu = 240000000L
```

## Uploading

Heltec Vision Master E213 supports the following uploading protocols:

- `cmsis-dap`
- `esp-bridge`
- `esp-builtin`
- `esp-prog`
- `espota`
- `esptool`
- `iot-bus-jtag`
- `jlink`
- `minimodule`
- `olimex-arm-usb-ocd`
- `olimex-arm-usb-ocd-h`
- `olimex-arm-usb-tiny-h`
- `olimex-jtag-tiny`
- `tumpa`

Default protocol is `esptool`

You can change upload protocol using [upload_protocol](../../../reference/platformio-ini/env/upload-protocol.md) option:

```ini
[env:heltec_vision_master_e213]
platform = espressif32
board = heltec_vision_master_e213

upload_protocol = esptool
```
