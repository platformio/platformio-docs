# UBW32 MX460

## Hardware

Platform [Microchip PIC32](../../platforms/microchippic32.md): Microchip's 32-bit portfolio with the MIPS microAptiv or M4K core offer high performance microcontrollers, and all the tools needed to develop your embedded projects. PIC32 MCUs gives your application the processing power, memory and peripherals your design needs!

| Specification | Value |
|---|---|
| **Microcontroller** | 32MX460F512L |
| **Frequency** | 80MHz |
| **Flash** | 508KB |
| **RAM** | 32KB |
| **Vendor** | [UBW32](http://www.schmalzhaus.com/UBW32/?utm_source=platformio.org&utm_medium=docs) |

## Configuration

Please use `ubw32_mx460` ID for [board](../../../reference/platformio-ini/env/board.md) option in ["platformio.ini" (Project Configuration File)](../../../reference/platformio-ini/index.md):

```ini
[env:ubw32_mx460]
platform = microchippic32
board = ubw32_mx460
```

You can override default UBW32 MX460 settings per build environment using `board_***` option, where `***` is a JSON object path from board manifest [ubw32_mx460.json](https://github.com/platformio/platform-microchippic32/blob/master/boards/ubw32_mx460.json). For example, `board_build.mcu`, `board_build.f_cpu`, etc.

```ini
[env:ubw32_mx460]
platform = microchippic32
board = ubw32_mx460

; change microcontroller
board_build.mcu = 32MX460F512L

; change MCU frequency
board_build.f_cpu = 80000000L
```

## Debugging
