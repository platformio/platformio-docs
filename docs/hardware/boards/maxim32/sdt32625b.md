# SDT32625B

## Hardware

Platform [Maxim 32](../../platforms/maxim32.md): Maxim's microcontrollers provide low-power, efficient, and secure solutions for challenging embedded applications. Maxim's processors embed cutting-edge technologies to secure data and intellectual property, proven analog circuitry for real-world applications, and battery-conserving low power operation.

| Specification | Value |
|---|---|
| **Microcontroller** | MAX32625ITK |
| **Frequency** | 96MHz |
| **Flash** | 512KB |
| **RAM** | 160KB |
| **Vendor** | [Sigma Delta Technologies](https://os.mbed.com/platforms/SDT32625B/?utm_source=platformio.org&utm_medium=docs) |

## Configuration

Use the board ID `sdt32625b` in the [board](../../../reference/platformio-ini/env/board.md) option of [platformio.ini](../../../reference/platformio-ini/index.md):

```ini
[env:sdt32625b]
platform = maxim32
board = sdt32625b
```

To override a setting of the board manifest [sdt32625b.json](https://github.com/platformio/platform-maxim32/blob/master/boards/sdt32625b.json) in a project environment, use an option named `board_` followed by the setting's JSON path, for example `board_build.mcu` or `board_build.f_cpu`:

```ini
[env:sdt32625b]
platform = maxim32
board = sdt32625b

; change microcontroller
board_build.mcu = max32625itk

; change MCU frequency
board_build.f_cpu = 96000000L
```
