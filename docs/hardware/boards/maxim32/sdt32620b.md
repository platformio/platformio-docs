# SDT32620B

## Hardware

Platform [Maxim 32](../../platforms/maxim32.md): Maxim's microcontrollers provide low-power, efficient, and secure solutions for challenging embedded applications. Maxim's processors embed cutting-edge technologies to secure data and intellectual property, proven analog circuitry for real-world applications, and battery-conserving low power operation.

| Specification | Value |
|---|---|
| **Microcontroller** | MAX32620IWG |
| **Frequency** | 96MHz |
| **Flash** | 2MB |
| **RAM** | 256KB |
| **Vendor** | [Sigma Delta Technologies](https://os.mbed.com/platforms/SDT32620B/?utm_source=platformio.org&utm_medium=docs) |

## Configuration

Use the board ID `sdt32620b` in the [board](../../../reference/platformio-ini/env/board.md) option of [platformio.ini](../../../reference/platformio-ini/index.md):

```ini
[env:sdt32620b]
platform = maxim32
board = sdt32620b
```

To override a setting of the board manifest [sdt32620b.json](https://github.com/platformio/platform-maxim32/blob/master/boards/sdt32620b.json) in a project environment, use an option named `board_` followed by the setting's JSON path, for example `board_build.mcu` or `board_build.f_cpu`:

```ini
[env:sdt32620b]
platform = maxim32
board = sdt32620b

; change microcontroller
board_build.mcu = max32620iwg

; change MCU frequency
board_build.f_cpu = 96000000L
```
