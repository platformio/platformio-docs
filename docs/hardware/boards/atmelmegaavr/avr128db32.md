# AVR128DB32

## Hardware

Platform [Atmel megaAVR](../../platforms/atmelmegaavr.mdx): 8-bit MCUs Built for Real-time Control with Core Independent Peripherals combining intelligent hardware peripherals along with the low-power capability of an AVR core, megaAVR microcontrollers (MCUs) broaden the effectiveness of your real-time control systems.

| Specification | Value |
|---|---|
| **Microcontroller** | AVR128DB32 |
| **Frequency** | 24MHz |
| **Flash** | 128KB |
| **RAM** | 16KB |
| **Vendor** | [Microchip](https://www.microchip.com/wwwproducts/en/AVR128DB32?utm_source=platformio.org&utm_medium=docs) |

## Configuration

Use the board ID `AVR128DB32` in the [board](../../../reference/platformio-ini/env/board.md) option of [platformio.ini](../../../reference/platformio-ini/index.md):

```ini
[env:AVR128DB32]
platform = atmelmegaavr
board = AVR128DB32
```

To override a setting of the board manifest [AVR128DB32.json](https://github.com/platformio/platform-atmelmegaavr/blob/master/boards/AVR128DB32.json) in a project environment, use an option named `board_` followed by the setting's JSON path, for example `board_build.mcu` or `board_build.f_cpu`:

```ini
[env:AVR128DB32]
platform = atmelmegaavr
board = AVR128DB32

; change microcontroller
board_build.mcu = avr128db32

; change MCU frequency
board_build.f_cpu = 24000000L
```

## Debugging
