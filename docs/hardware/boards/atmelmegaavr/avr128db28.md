# AVR128DB28

## Hardware

Platform [Atmel megaAVR](../../platforms/atmelmegaavr.mdx): 8-bit MCUs Built for Real-time Control with Core Independent Peripherals combining intelligent hardware peripherals along with the low-power capability of an AVR core, megaAVR microcontrollers (MCUs) broaden the effectiveness of your real-time control systems.

| Specification | Value |
|---|---|
| **Microcontroller** | AVR128DB28 |
| **Frequency** | 24MHz |
| **Flash** | 128KB |
| **RAM** | 16KB |
| **Vendor** | [Microchip](https://www.microchip.com/wwwproducts/en/AVR128DB28?utm_source=platformio.org&utm_medium=docs) |

## Configuration

Please use `AVR128DB28` ID for [board](../../../reference/platformio-ini/env/board.md) option in ["platformio.ini" (Project Configuration File)](../../../reference/platformio-ini/index.md):

```ini
[env:AVR128DB28]
platform = atmelmegaavr
board = AVR128DB28
```

You can override default AVR128DB28 settings per build environment using `board_***` option, where `***` is a JSON object path from board manifest [AVR128DB28.json](https://github.com/platformio/platform-atmelmegaavr/blob/master/boards/AVR128DB28.json). For example, `board_build.mcu`, `board_build.f_cpu`, etc.

```ini
[env:AVR128DB28]
platform = atmelmegaavr
board = AVR128DB28

; change microcontroller
board_build.mcu = avr128db28

; change MCU frequency
board_build.f_cpu = 24000000L
```
