# Nordic nRF52833-DK

## Hardware

Platform [Nordic nRF52](../../platforms/nordicnrf52.mdx): The nRF52 Series are built for speed to carry out increasingly complex tasks in the shortest possible time and return to sleep, conserving precious battery power. They have a Cortex-M4F processor which makes them quite capable Bluetooth Smart SoCs.

| Specification | Value |
|---|---|
| **Microcontroller** | NRF52833 |
| **Frequency** | 64MHz |
| **Flash** | 512KB |
| **RAM** | 128KB |
| **Vendor** | [Nordic](https://www.nordicsemi.com/Products/Development-hardware/nrf52833-dk?utm_source=platformio.org&utm_medium=docs) |

## Configuration

Use the board ID `nrf52833_dk` in the [board](../../../reference/platformio-ini/env/board.md) option of [platformio.ini](../../../reference/platformio-ini/index.md):

```ini
[env:nrf52833_dk]
platform = nordicnrf52
board = nrf52833_dk
```

To override a setting of the board manifest [nrf52833_dk.json](https://github.com/platformio/platform-nordicnrf52/blob/master/boards/nrf52833_dk.json) in a project environment, use an option named `board_` followed by the setting's JSON path, for example `board_build.mcu` or `board_build.f_cpu`:

```ini
[env:nrf52833_dk]
platform = nordicnrf52
board = nrf52833_dk

; change microcontroller
board_build.mcu = nrf52833

; change MCU frequency
board_build.f_cpu = 64000000L
```

## Uploading

Nordic nRF52833-DK supports these upload protocols:

- `blackmagic`
- `cmsis-dap`
- `jlink`
- `mbed`
- `nrfjprog`
- `stlink`

The default is `jlink`.

To use another one, set the [upload_protocol](../../../reference/platformio-ini/env/upload-protocol.md) option:

```ini
[env:nrf52833_dk]
platform = nordicnrf52
board = nrf52833_dk

upload_protocol = jlink
```

## Debugging

The Nordic nRF52833-DK has an on-board debug probe: [Debugging](../../../guides/debugging/index.md) works without extra hardware.

Select the probe with the [debug_tool](../../../reference/platformio-ini/env/debug-tool.md) option in [platformio.ini](../../../reference/platformio-ini/index.md). If you do not set it, the probe marked as default is used.

:::warning

Most debug probes need a driver or udev rules. See the probe's page for instructions.

:::
