# NXP mbed LPC1768

## Hardware

Platform [NXP LPC](../../platforms/nxplpc.md): The NXP LPC is a family of 32-bit microcontroller integrated circuits by NXP Semiconductors. The LPC chips are grouped into related series that are based around the same 32-bit ARM processor core, such as the Cortex-M4F, Cortex-M3, Cortex-M0+, or Cortex-M0. Internally, each microcontroller consists of the processor core, static RAM memory, flash memory, debugging interface, and various peripherals.

| Specification | Value |
|---|---|
| **Microcontroller** | LPC1768 |
| **Frequency** | 96MHz |
| **Flash** | 512KB |
| **RAM** | 64KB |
| **Vendor** | [NXP](http://developer.mbed.org/platforms/mbed-LPC1768/?utm_source=platformio.org&utm_medium=docs) |

## Configuration

Use the board ID `lpc1768` in the [board](../../../reference/platformio-ini/env/board.md) option of [platformio.ini](../../../reference/platformio-ini/index.md):

```ini
[env:lpc1768]
platform = nxplpc
board = lpc1768
```

To override a setting of the board manifest [lpc1768.json](https://github.com/platformio/platform-nxplpc/blob/master/boards/lpc1768.json) in a project environment, use an option named `board_` followed by the setting's JSON path, for example `board_build.mcu` or `board_build.f_cpu`:

```ini
[env:lpc1768]
platform = nxplpc
board = lpc1768

; change microcontroller
board_build.mcu = lpc1768

; change MCU frequency
board_build.f_cpu = 96000000L
```

## Uploading

NXP mbed LPC1768 supports these upload protocols:

- `blackmagic`
- `cmsis-dap`
- `jlink`
- `mbed`

The default is `mbed`.

To use another one, set the [upload_protocol](../../../reference/platformio-ini/env/upload-protocol.md) option:

```ini
[env:lpc1768]
platform = nxplpc
board = lpc1768

upload_protocol = mbed
```

## Debugging

The NXP mbed LPC1768 has an on-board debug probe: [Debugging](../../../guides/debugging/index.md) works without extra hardware.

Select the probe with the [debug_tool](../../../reference/platformio-ini/env/debug-tool.md) option in [platformio.ini](../../../reference/platformio-ini/index.md). If you do not set it, the probe marked as default is used.

:::warning

Most debug probes need a driver or udev rules. See the probe's page for instructions.

:::
