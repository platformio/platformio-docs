# Microduino Core (Atmega168PA@8M,3.3V)

## Hardware

Platform [Atmel AVR](../../platforms/atmelavr.mdx): Atmel AVR 8-bit MCUs deliver a unique combination of performance, power efficiency and design flexibility. Optimized to speed time to market-and easily adapt to new ones-they are based on the industry's most code-efficient architecture for C and assembly programming

| Specification | Value |
|---|---|
| **Microcontroller** | ATMEGA168P |
| **Frequency** | 8MHz |
| **Flash** | 15.50KB |
| **RAM** | 1KB |
| **Vendor** | [Microduino](http://wiki.microduinoinc.com/Microduino-Module_Core?utm_source=platformio.org&utm_medium=docs) |

## Configuration

Use the board ID `168pa8m` in the [board](../../../reference/platformio-ini/env/board.md) option of [platformio.ini](../../../reference/platformio-ini/index.md):

```ini
[env:168pa8m]
platform = atmelavr
board = 168pa8m
```

To override a setting of the board manifest [168pa8m.json](https://github.com/platformio/platform-atmelavr/blob/master/boards/168pa8m.json) in a project environment, use an option named `board_` followed by the setting's JSON path, for example `board_build.mcu` or `board_build.f_cpu`:

```ini
[env:168pa8m]
platform = atmelavr
board = 168pa8m

; change microcontroller
board_build.mcu = atmega168p

; change MCU frequency
board_build.f_cpu = 8000000L
```

## Debugging

The Microduino Core (Atmega168PA@8M,3.3V) has no on-board debug probe: [Debugging](../../../guides/debugging/index.md) needs one of the external probes below.

Select the probe with the [debug_tool](../../../reference/platformio-ini/env/debug-tool.md) option in [platformio.ini](../../../reference/platformio-ini/index.md). If you do not set it, the probe marked as default is used.

:::warning

Most debug probes need a driver or udev rules. See the probe's page for instructions.

:::

| Compatible probes | On-board | Default |
|---|---|---|
| [simavr](../../debug-probes/simavr.md) |  | Yes |
