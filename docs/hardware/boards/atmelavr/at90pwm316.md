# Atmel AT90PWM316

## Hardware

Platform [Atmel AVR](../../platforms/atmelavr.mdx): Atmel AVR 8-bit MCUs deliver a unique combination of performance, power efficiency and design flexibility. Optimized to speed time to market-and easily adapt to new ones-they are based on the industry's most code-efficient architecture for C and assembly programming

| Specification | Value |
|---|---|
| **Microcontroller** | AT90PWM316 |
| **Frequency** | 16MHz |
| **Flash** | 16KB |
| **RAM** | 1KB |
| **Vendor** | [Microchip](http://www.microchip.com/wwwproducts/en/AT90PWM316?utm_source=platformio.org&utm_medium=docs) |

## Configuration

Use the board ID `at90pwm316` in the [board](../../../reference/platformio-ini/env/board.md) option of [platformio.ini](../../../reference/platformio-ini/index.md):

```ini
[env:at90pwm316]
platform = atmelavr
board = at90pwm316
```

To override a setting of the board manifest [at90pwm316.json](https://github.com/platformio/platform-atmelavr/blob/master/boards/at90pwm316.json) in a project environment, use an option named `board_` followed by the setting's JSON path, for example `board_build.mcu` or `board_build.f_cpu`:

```ini
[env:at90pwm316]
platform = atmelavr
board = at90pwm316

; change microcontroller
board_build.mcu = at90pwm316

; change MCU frequency
board_build.f_cpu = 16000000L
```
