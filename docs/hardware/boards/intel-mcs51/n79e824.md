# Generic N79E824

## Hardware

Platform [Intel MCS-51 (8051)](../../platforms/intel-mcs51.md): The Intel MCS-51 (commonly termed 8051) is an internally Harvard architecture, complex instruction set computer (CISC) instruction set, single chip microcontroller (uC) series developed by Intel in 1980 for use in embedded systems.

| Specification | Value |
|---|---|
| **Microcontroller** | N79E824 |
| **Frequency** | 6MHz |
| **Flash** | 8KB |
| **RAM** | 256B |
| **Vendor** | [Nuvoton](https://www.nuvoton.com/products/microcontrollers/8bit-8051-mcus/low-pin-count-8051-series/n79e824/?utm_source=platformio.org&utm_medium=docs) |

## Configuration

Use the board ID `N79E824` in the [board](../../../reference/platformio-ini/env/board.md) option of [platformio.ini](../../../reference/platformio-ini/index.md):

```ini
[env:N79E824]
platform = intel_mcs51
board = N79E824
```

To override a setting of the board manifest [N79E824.json](https://github.com/platformio/platform-intel_mcs51/blob/master/boards/N79E824.json) in a project environment, use an option named `board_` followed by the setting's JSON path, for example `board_build.mcu` or `board_build.f_cpu`:

```ini
[env:N79E824]
platform = intel_mcs51
board = N79E824

; change microcontroller
board_build.mcu = n79e824

; change MCU frequency
board_build.f_cpu = 6000000L
```
