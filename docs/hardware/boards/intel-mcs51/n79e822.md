# Generic N79E822

## Hardware

Platform [Intel MCS-51 (8051)](../../platforms/intel-mcs51.md): The Intel MCS-51 (commonly termed 8051) is an internally Harvard architecture, complex instruction set computer (CISC) instruction set, single chip microcontroller (uC) series developed by Intel in 1980 for use in embedded systems.

| Specification | Value |
|---|---|
| **Microcontroller** | N79E822 |
| **Frequency** | 6MHz |
| **Flash** | 2KB |
| **RAM** | 256B |
| **Vendor** | [Nuvoton](https://www.nuvoton.com/products/microcontrollers/8bit-8051-mcus/low-pin-count-8051-series/n79e822/?utm_source=platformio.org&utm_medium=docs) |

## Configuration

Please use `N79E822` ID for [board](../../../reference/platformio-ini/env/board.md) option in ["platformio.ini" (Project Configuration File)](../../../reference/platformio-ini/index.md):

```ini
[env:N79E822]
platform = intel_mcs51
board = N79E822
```

You can override default Generic N79E822 settings per build environment using `board_***` option, where `***` is a JSON object path from board manifest [N79E822.json](https://github.com/platformio/platform-intel_mcs51/blob/master/boards/N79E822.json). For example, `board_build.mcu`, `board_build.f_cpu`, etc.

```ini
[env:N79E822]
platform = intel_mcs51
board = N79E822

; change microcontroller
board_build.mcu = n79e822

; change MCU frequency
board_build.f_cpu = 6000000L
```

## Debugging

[Debugging](../../../guides/debugging/index.md) currently does not support Generic N79E822 board.
