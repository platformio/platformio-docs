# Generic W79E2051

## Hardware

Platform [Intel MCS-51 (8051)](../../platforms/intel-mcs51.md): The Intel MCS-51 (commonly termed 8051) is an internally Harvard architecture, complex instruction set computer (CISC) instruction set, single chip microcontroller (uC) series developed by Intel in 1980 for use in embedded systems.

| Specification | Value |
|---|---|
| **Microcontroller** | W79E2051 |
| **Frequency** | 22MHz |
| **Flash** | 2KB |
| **RAM** | 256B |
| **Vendor** | [Nuvoton](https://www.nuvoton.com/products/microcontrollers/8bit-8051-mcus/low-pin-count-8051-series/w79e2051/?utm_source=platformio.org&utm_medium=docs) |

## Configuration

Please use `W79E2051` ID for [board](../../../reference/platformio-ini/env/board.md) option in ["platformio.ini" (Project Configuration File)](../../../reference/platformio-ini/index.md):

```ini
[env:W79E2051]
platform = intel_mcs51
board = W79E2051
```

You can override default Generic W79E2051 settings per build environment using `board_***` option, where `***` is a JSON object path from board manifest [W79E2051.json](https://github.com/platformio/platform-intel_mcs51/blob/master/boards/W79E2051.json). For example, `board_build.mcu`, `board_build.f_cpu`, etc.

```ini
[env:W79E2051]
platform = intel_mcs51
board = W79E2051

; change microcontroller
board_build.mcu = w79e2051

; change MCU frequency
board_build.f_cpu = 22118400L
```

## Debugging

[Debugging](../../../guides/debugging/index.md) currently does not support Generic W79E2051 board.
