# CH559

## Hardware

Platform [Intel MCS-51 (8051)](../../platforms/intel-mcs51.md): The Intel MCS-51 (commonly termed 8051) is an internally Harvard architecture, complex instruction set computer (CISC) instruction set, single chip microcontroller (uC) series developed by Intel in 1980 for use in embedded systems.

| Specification | Value |
|---|---|
| **Microcontroller** | CH559 |
| **Frequency** | 12MHz |
| **Flash** | 64KB |
| **RAM** | 6.25KB |
| **Vendor** | [WCH](http://www.wch-ic.com/products/CH559.html?utm_source=platformio.org&utm_medium=docs) |

## Configuration

Use the board ID `CH559` in the [board](../../../reference/platformio-ini/env/board.md) option of [platformio.ini](../../../reference/platformio-ini/index.md):

```ini
[env:CH559]
platform = intel_mcs51
board = CH559
```

To override a setting of the board manifest [CH559.json](https://github.com/platformio/platform-intel_mcs51/blob/master/boards/CH559.json) in a project environment, use an option named `board_` followed by the setting's JSON path, for example `board_build.mcu` or `board_build.f_cpu`:

```ini
[env:CH559]
platform = intel_mcs51
board = CH559

; change microcontroller
board_build.mcu = ch559

; change MCU frequency
board_build.f_cpu = 12000000L
```

## Debugging

[Debugging](../../../guides/debugging/index.md) does not support the CH559 yet.
