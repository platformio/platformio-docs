# Generic IRC15W207S

## Hardware

Platform [Intel MCS-51 (8051)](../../platforms/intel-mcs51.md): The Intel MCS-51 (commonly termed 8051) is an internally Harvard architecture, complex instruction set computer (CISC) instruction set, single chip microcontroller (uC) series developed by Intel in 1980 for use in embedded systems.

| Specification | Value |
|---|---|
| **Microcontroller** | IRC15W207S |
| **Frequency** | 11MHz |
| **Flash** | 7.50KB |
| **RAM** | 256B |
| **Vendor** | [STC](https://www.stcmicro.com/STC/STC15W204S.html?utm_source=platformio.org&utm_medium=docs) |

## Configuration

Please use `IRC15W207S` ID for [board](../../../reference/platformio-ini/env/board.md) option in ["platformio.ini" (Project Configuration File)](../../../reference/platformio-ini/index.md):

```ini
[env:IRC15W207S]
platform = intel_mcs51
board = IRC15W207S
```

You can override default Generic IRC15W207S settings per build environment using `board_***` option, where `***` is a JSON object path from board manifest [IRC15W207S.json](https://github.com/platformio/platform-intel_mcs51/blob/master/boards/IRC15W207S.json). For example, `board_build.mcu`, `board_build.f_cpu`, etc.

```ini
[env:IRC15W207S]
platform = intel_mcs51
board = IRC15W207S

; change microcontroller
board_build.mcu = irc15w207s

; change MCU frequency
board_build.f_cpu = 11059200L
```
