# Generic IRC15W207S

## Hardware

Platform [Intel MCS-51 (8051)](../../platforms/intel-mcs51.md): The Intel MCS-51 (commonly termed 8051) is an internally Harvard architecture, complex instruction set computer (CISC) instruction set, single chip microcontroller (uC) series developed by Intel in 1980 for use in embedded systems.

| Specification | Value |
|---|---|
| **Microcontroller** | IRC15W207S |
| **Frequency** | 11MHz |
| **Flash** | 7.50KB |
| **RAM** | 256B |
| **Vendor** | [STC](https://www.stcmicro.com/STC/STC15W204S.html?utm_source=platformio.org&utm_medium=docs) |

## Configuration

Use the board ID `IRC15W207S` in the [board](../../../reference/platformio-ini/env/board.md) option of [platformio.ini](../../../reference/platformio-ini/index.md):

```ini
[env:IRC15W207S]
platform = intel_mcs51
board = IRC15W207S
```

To override a setting of the board manifest [IRC15W207S.json](https://github.com/platformio/platform-intel_mcs51/blob/master/boards/IRC15W207S.json) in a project environment, use an option named `board_` followed by the setting's JSON path, for example `board_build.mcu` or `board_build.f_cpu`:

```ini
[env:IRC15W207S]
platform = intel_mcs51
board = IRC15W207S

; change microcontroller
board_build.mcu = irc15w207s

; change MCU frequency
board_build.f_cpu = 11059200L
```
