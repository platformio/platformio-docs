# Generic W79E8213

## Hardware

Platform [Intel MCS-51 (8051)](../../platforms/intel-mcs51.md): The Intel MCS-51 (commonly termed 8051) is an internally Harvard architecture, complex instruction set computer (CISC) instruction set, single chip microcontroller (uC) series developed by Intel in 1980 for use in embedded systems.

| Specification | Value |
|---|---|
| **Microcontroller** | W79E8213 |
| **Frequency** | 20MHz |
| **Flash** | 4KB |
| **RAM** | 128B |
| **Vendor** | [Nuvoton](https://www.nuvoton.com/products/microcontrollers/8bit-8051-mcus/low-pin-count-8051-series/w79e8213/?utm_source=platformio.org&utm_medium=docs) |

## Configuration

Use the board ID `W79E8213` in the [board](../../../reference/platformio-ini/env/board.md) option of [platformio.ini](../../../reference/platformio-ini/index.md):

```ini
[env:W79E8213]
platform = intel_mcs51
board = W79E8213
```

To override a setting of the board manifest [W79E8213.json](https://github.com/platformio/platform-intel_mcs51/blob/master/boards/W79E8213.json) in a project environment, use an option named `board_` followed by the setting's JSON path, for example `board_build.mcu` or `board_build.f_cpu`:

```ini
[env:W79E8213]
platform = intel_mcs51
board = W79E8213

; change microcontroller
board_build.mcu = w79e8213

; change MCU frequency
board_build.f_cpu = 20000000L
```
