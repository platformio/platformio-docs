# Generic STC15W4K40S4

## Hardware

Platform [Intel MCS-51 (8051)](../../platforms/intel-mcs51.md): The Intel MCS-51 (commonly termed 8051) is an internally Harvard architecture, complex instruction set computer (CISC) instruction set, single chip microcontroller (uC) series developed by Intel in 1980 for use in embedded systems.

| Specification | Value |
|---|---|
| **Microcontroller** | STC15W4K40S4 |
| **Frequency** | 11MHz |
| **Flash** | 40KB |
| **RAM** | 4KB |
| **Vendor** | [STC](http://www.stcmicro.com/STC/STC15W4K32S4.html?utm_source=platformio.org&utm_medium=docs) |

## Configuration

Use the board ID `STC15W4K40S4` in the [board](../../../reference/platformio-ini/env/board.md) option of [platformio.ini](../../../reference/platformio-ini/index.md):

```ini
[env:STC15W4K40S4]
platform = intel_mcs51
board = STC15W4K40S4
```

To override a setting of the board manifest [STC15W4K40S4.json](https://github.com/platformio/platform-intel_mcs51/blob/master/boards/STC15W4K40S4.json) in a project environment, use an option named `board_` followed by the setting's JSON path, for example `board_build.mcu` or `board_build.f_cpu`:

```ini
[env:STC15W4K40S4]
platform = intel_mcs51
board = STC15W4K40S4

; change microcontroller
board_build.mcu = stc15w4k40s4

; change MCU frequency
board_build.f_cpu = 11059200L
```
