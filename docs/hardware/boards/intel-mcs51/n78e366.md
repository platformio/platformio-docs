# Generic N78E366

## Hardware

Platform [Intel MCS-51 (8051)](../../platforms/intel-mcs51.md): The Intel MCS-51 (commonly termed 8051) is an internally Harvard architecture, complex instruction set computer (CISC) instruction set, single chip microcontroller (uC) series developed by Intel in 1980 for use in embedded systems.

| Specification | Value |
|---|---|
| **Microcontroller** | N78E366 |
| **Frequency** | 22MHz |
| **Flash** | 64KB |
| **RAM** | 1.25KB |
| **Vendor** | [Nuvoton](https://www.nuvoton.com/products/microcontrollers/8bit-8051-mcus/standard-8051-series/n78e366a/?utm_source=platformio.org&utm_medium=docs) |

## Configuration

Use the board ID `N78E366` in the [board](../../../reference/platformio-ini/env/board.md) option of [platformio.ini](../../../reference/platformio-ini/index.md):

```ini
[env:N78E366]
platform = intel_mcs51
board = N78E366
```

To override a setting of the board manifest [N78E366.json](https://github.com/platformio/platform-intel_mcs51/blob/master/boards/N78E366.json) in a project environment, use an option named `board_` followed by the setting's JSON path, for example `board_build.mcu` or `board_build.f_cpu`:

```ini
[env:N78E366]
platform = intel_mcs51
board = N78E366

; change microcontroller
board_build.mcu = n78e366

; change MCU frequency
board_build.f_cpu = 22118400L
```

## Debugging

[Debugging](../../../guides/debugging/index.md) does not support the Generic N78E366 yet.
