# Generic N78E366

## Hardware

Platform [Intel MCS-51 (8051)](../../platforms/intel-mcs51.md): The Intel MCS-51 (commonly termed 8051) is an internally Harvard architecture, complex instruction set computer (CISC) instruction set, single chip microcontroller (uC) series developed by Intel in 1980 for use in embedded systems.

| Specification | Value |
|---|---|
| **Microcontroller** | N78E366 |
| **Frequency** | 22MHz |
| **Flash** | 64KB |
| **RAM** | 1.25KB |
| **Vendor** | [Nuvoton](https://www.nuvoton.com/products/microcontrollers/8bit-8051-mcus/standard-8051-series/n78e366a/?utm_source=platformio.org&utm_medium=docs) |

## Configuration

Please use `N78E366` ID for [board](../../../reference/platformio-ini/env/board.md) option in ["platformio.ini" (Project Configuration File)](../../../reference/platformio-ini/index.md):

```ini
[env:N78E366]
platform = intel_mcs51
board = N78E366
```

You can override default Generic N78E366 settings per build environment using `board_***` option, where `***` is a JSON object path from board manifest [N78E366.json](https://github.com/platformio/platform-intel_mcs51/blob/master/boards/N78E366.json). For example, `board_build.mcu`, `board_build.f_cpu`, etc.

```ini
[env:N78E366]
platform = intel_mcs51
board = N78E366

; change microcontroller
board_build.mcu = n78e366

; change MCU frequency
board_build.f_cpu = 22118400L
```

## Debugging

[Debugging](../../../guides/debugging/index.md) currently does not support Generic N78E366 board.
