# Generic AT89S52

## Hardware

Platform [Intel MCS-51 (8051)](../../platforms/intel-mcs51.md): The Intel MCS-51 (commonly termed 8051) is an internally Harvard architecture, complex instruction set computer (CISC) instruction set, single chip microcontroller (uC) series developed by Intel in 1980 for use in embedded systems.

| Specification | Value |
|---|---|
| **Microcontroller** | AT89S52 |
| **Frequency** | 11MHz |
| **Flash** | 8KB |
| **RAM** | 256B |
| **Vendor** | [Microchip & Atmel](https://www.microchip.com/wwwproducts/en/AT89S52?utm_source=platformio.org&utm_medium=docs) |

## Configuration

Use the board ID `AT89S52` in the [board](../../../reference/platformio-ini/env/board.md) option of [platformio.ini](../../../reference/platformio-ini/index.md):

```ini
[env:AT89S52]
platform = intel_mcs51
board = AT89S52
```

To override a setting of the board manifest [AT89S52.json](https://github.com/platformio/platform-intel_mcs51/blob/master/boards/AT89S52.json) in a project environment, use an option named `board_` followed by the setting's JSON path, for example `board_build.mcu` or `board_build.f_cpu`:

```ini
[env:AT89S52]
platform = intel_mcs51
board = AT89S52

; change microcontroller
board_build.mcu = at89s52

; change MCU frequency
board_build.f_cpu = 11059200L
```

## Uploading

Generic AT89S52 supports these upload protocols:

- `avrisp`
- `usbasp`

The default is `avrdude`.

To use another one, set the [upload_protocol](../../../reference/platformio-ini/env/upload-protocol.md) option:

```ini
[env:AT89S52]
platform = intel_mcs51
board = AT89S52

upload_protocol = avrdude
```

## Debugging

[Debugging](../../../guides/debugging/index.md) does not support the Generic AT89S52 yet.
