# Generic N76E003

## Hardware

Platform [Intel MCS-51 (8051)](../../platforms/intel-mcs51.md): The Intel MCS-51 (commonly termed 8051) is an internally Harvard architecture, complex instruction set computer (CISC) instruction set, single chip microcontroller (uC) series developed by Intel in 1980 for use in embedded systems.

| Specification | Value |
|---|---|
| **Microcontroller** | N76E003 |
| **Frequency** | 16MHz |
| **Flash** | 18KB |
| **RAM** | 1KB |
| **Vendor** | [Nuvoton](https://www.nuvoton.com/products/microcontrollers/8bit-8051-mcus/low-pin-count-8051-series/n76e003/?utm_source=platformio.org&utm_medium=docs) |

## Configuration

Please use `N76E003` ID for [board](../../../reference/platformio-ini/env/board.md) option in ["platformio.ini" (Project Configuration File)](../../../reference/platformio-ini/index.md):

```ini
[env:N76E003]
platform = intel_mcs51
board = N76E003
```

You can override default Generic N76E003 settings per build environment using `board_***` option, where `***` is a JSON object path from board manifest [N76E003.json](https://github.com/platformio/platform-intel_mcs51/blob/master/boards/N76E003.json). For example, `board_build.mcu`, `board_build.f_cpu`, etc.

```ini
[env:N76E003]
platform = intel_mcs51
board = N76E003

; change microcontroller
board_build.mcu = n76e003

; change MCU frequency
board_build.f_cpu = 16000000L
```

## Debugging

[Debugging](../../../guides/debugging/index.md) currently does not support Generic N76E003 board.
