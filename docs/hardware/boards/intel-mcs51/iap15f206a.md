# Generic IAP15F206A

## Hardware

Platform [Intel MCS-51 (8051)](../../platforms/intel-mcs51.md): The Intel MCS-51 (commonly termed 8051) is an internally Harvard architecture, complex instruction set computer (CISC) instruction set, single chip microcontroller (uC) series developed by Intel in 1980 for use in embedded systems.

| Specification | Value |
|---|---|
| **Microcontroller** | IAP15F206A |
| **Frequency** | 11MHz |
| **Flash** | 6KB |
| **RAM** | 256B |
| **Vendor** | [STC](https://www.stcmicro.com/STC/STC15F204EA.html?utm_source=platformio.org&utm_medium=docs) |

## Configuration

Use the board ID `IAP15F206A` in the [board](../../../reference/platformio-ini/env/board.md) option of [platformio.ini](../../../reference/platformio-ini/index.md):

```ini
[env:IAP15F206A]
platform = intel_mcs51
board = IAP15F206A
```

To override a setting of the board manifest [IAP15F206A.json](https://github.com/platformio/platform-intel_mcs51/blob/master/boards/IAP15F206A.json) in a project environment, use an option named `board_` followed by the setting's JSON path, for example `board_build.mcu` or `board_build.f_cpu`:

```ini
[env:IAP15F206A]
platform = intel_mcs51
board = IAP15F206A

; change microcontroller
board_build.mcu = iap15f206a

; change MCU frequency
board_build.f_cpu = 11059200L
```

## Debugging

[Debugging](../../../guides/debugging/index.md) does not support the Generic IAP15F206A yet.
