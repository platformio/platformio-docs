# Generic IRC15W107

## Hardware

Platform [Intel MCS-51 (8051)](../../platforms/intel-mcs51.md): The Intel MCS-51 (commonly termed 8051) is an internally Harvard architecture, complex instruction set computer (CISC) instruction set, single chip microcontroller (uC) series developed by Intel in 1980 for use in embedded systems.

| Specification | Value |
|---|---|
| **Microcontroller** | IRC15W107 |
| **Frequency** | 11MHz |
| **Flash** | 7KB |
| **RAM** | 128B |
| **Vendor** | [STC](https://www.stcmicro.com/STC/STC15W104.html?utm_source=platformio.org&utm_medium=docs) |

## Configuration

Use the board ID `IRC15W107` in the [board](../../../reference/platformio-ini/env/board.md) option of [platformio.ini](../../../reference/platformio-ini/index.md):

```ini
[env:IRC15W107]
platform = intel_mcs51
board = IRC15W107
```

To override a setting of the board manifest [IRC15W107.json](https://github.com/platformio/platform-intel_mcs51/blob/master/boards/IRC15W107.json) in a project environment, use an option named `board_` followed by the setting's JSON path, for example `board_build.mcu` or `board_build.f_cpu`:

```ini
[env:IRC15W107]
platform = intel_mcs51
board = IRC15W107

; change microcontroller
board_build.mcu = irc15w107

; change MCU frequency
board_build.f_cpu = 11059200L
```
