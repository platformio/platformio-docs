# Generic STC15F103W

## Hardware

Platform [Intel MCS-51 (8051)](../../platforms/intel-mcs51.md): The Intel MCS-51 (commonly termed 8051) is an internally Harvard architecture, complex instruction set computer (CISC) instruction set, single chip microcontroller (uC) series developed by Intel in 1980 for use in embedded systems.

| Specification | Value |
|---|---|
| **Microcontroller** | STC15F103W |
| **Frequency** | 11MHz |
| **Flash** | 3KB |
| **RAM** | 128B |
| **Vendor** | [STC](https://www.stcmicro.com/STC/STC15F104W.html?utm_source=platformio.org&utm_medium=docs) |

## Configuration

Please use `STC15F103W` ID for [board](../../../reference/platformio-ini/env/board.md) option in ["platformio.ini" (Project Configuration File)](../../../reference/platformio-ini/index.md):

```ini
[env:STC15F103W]
platform = intel_mcs51
board = STC15F103W
```

You can override default Generic STC15F103W settings per build environment using `board_***` option, where `***` is a JSON object path from board manifest [STC15F103W.json](https://github.com/platformio/platform-intel_mcs51/blob/master/boards/STC15F103W.json). For example, `board_build.mcu`, `board_build.f_cpu`, etc.

```ini
[env:STC15F103W]
platform = intel_mcs51
board = STC15F103W

; change microcontroller
board_build.mcu = stc15f103w

; change MCU frequency
board_build.f_cpu = 11059200L
```

## Debugging

[Debugging](../../../guides/debugging/index.md) currently does not support Generic STC15F103W board.
