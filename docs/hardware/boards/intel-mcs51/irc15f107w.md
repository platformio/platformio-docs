# Generic IRC15F107W

## Hardware

Platform [Intel MCS-51 (8051)](../../platforms/intel-mcs51.md): The Intel MCS-51 (commonly termed 8051) is an internally Harvard architecture, complex instruction set computer (CISC) instruction set, single chip microcontroller (uC) series developed by Intel in 1980 for use in embedded systems.

| Specification | Value |
|---|---|
| **Microcontroller** | IRC15F107W |
| **Frequency** | 11MHz |
| **Flash** | 6KB |
| **RAM** | 128B |
| **Vendor** | [STC](https://www.stcmicro.com/STC/STC15F104W.html?utm_source=platformio.org&utm_medium=docs) |

## Configuration

Please use `IRC15F107W` ID for [board](../../../reference/platformio-ini/env/board.md) option in ["platformio.ini" (Project Configuration File)](../../../reference/platformio-ini/index.md):

```ini
[env:IRC15F107W]
platform = intel_mcs51
board = IRC15F107W
```

You can override default Generic IRC15F107W settings per build environment using `board_***` option, where `***` is a JSON object path from board manifest [IRC15F107W.json](https://github.com/platformio/platform-intel_mcs51/blob/master/boards/IRC15F107W.json). For example, `board_build.mcu`, `board_build.f_cpu`, etc.

```ini
[env:IRC15F107W]
platform = intel_mcs51
board = IRC15F107W

; change microcontroller
board_build.mcu = irc15f107w

; change MCU frequency
board_build.f_cpu = 11059200L
```

## Debugging
