# TI LaunchPad MSP-EXP430G2553LP

## Hardware

Platform [TI MSP430](../../platforms/timsp430.md): MSP430 microcontrollers (MCUs) from Texas Instruments (TI) are 16-bit, RISC-based, mixed-signal processors designed for ultra-low power. These MCUs offer the lowest power consumption and the perfect mix of integrated peripherals for thousands of applications.

| Specification | Value |
|---|---|
| **Microcontroller** | MSP430G2553 |
| **Frequency** | 16MHz |
| **Flash** | 16KB |
| **RAM** | 512B |
| **Vendor** | [TI](http://www.ti.com/ww/en/launchpad/launchpads-msp430-msp-exp430g2.html?utm_source=platformio.org&utm_medium=docs) |

## Configuration

Please use `lpmsp430g2553` ID for [board](../../../reference/platformio-ini/env/board.md) option in ["platformio.ini" (Project Configuration File)](../../../reference/platformio-ini/index.md):

```ini
[env:lpmsp430g2553]
platform = timsp430
board = lpmsp430g2553
```

You can override default TI LaunchPad MSP-EXP430G2553LP settings per build environment using `board_***` option, where `***` is a JSON object path from board manifest [lpmsp430g2553.json](https://github.com/platformio/platform-timsp430/blob/master/boards/lpmsp430g2553.json). For example, `board_build.mcu`, `board_build.f_cpu`, etc.

```ini
[env:lpmsp430g2553]
platform = timsp430
board = lpmsp430g2553

; change microcontroller
board_build.mcu = msp430g2553

; change MCU frequency
board_build.f_cpu = 16000000L
```

## Debugging

[Debugging](../../../guides/debugging/index.md) - "1-click" solution for debugging with a zero configuration.

:::warning

You will need to install debug tool drivers depending on your system. Please click on compatible debug tool below for the further instructions and configuration information.

:::

You can switch between debugging [Tools & Debug Probes](../../../guides/debugging/index.md#debugging-tools) using [debug_tool](../../../reference/platformio-ini/env/debug-tool.md) option in ["platformio.ini" (Project Configuration File)](../../../reference/platformio-ini/index.md).

TI LaunchPad MSP-EXP430G2553LP has on-board debug probe and **IS READY** for debugging. You don't need to use/buy external debug probe.

| Compatible Tools | On-board | Default |
|---|---|---|
| [MSP Debug](../../debug-probes/mspdebug.md) | Yes | Yes |
