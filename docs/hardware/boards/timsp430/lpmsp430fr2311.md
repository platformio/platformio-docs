# TI LaunchPad MSP-EXP430FR2311LP

## Hardware

Platform [TI MSP430](../../platforms/timsp430.md): MSP430 microcontrollers (MCUs) from Texas Instruments (TI) are 16-bit, RISC-based, mixed-signal processors designed for ultra-low power. These MCUs offer the lowest power consumption and the perfect mix of integrated peripherals for thousands of applications.

| Specification | Value |
|---|---|
| **Microcontroller** | MSP430FR2311 |
| **Frequency** | 16MHz |
| **Flash** | 3.75KB |
| **RAM** | 1KB |
| **Vendor** | [TI](http://www.ti.com/product/MSP430FR2311?utm_source=platformio.org&utm_medium=docs) |

## Configuration

Use the board ID `lpmsp430fr2311` in the [board](../../../reference/platformio-ini/env/board.md) option of [platformio.ini](../../../reference/platformio-ini/index.md):

```ini
[env:lpmsp430fr2311]
platform = timsp430
board = lpmsp430fr2311
```

To override a setting of the board manifest [lpmsp430fr2311.json](https://github.com/platformio/platform-timsp430/blob/master/boards/lpmsp430fr2311.json) in a project environment, use an option named `board_` followed by the setting's JSON path, for example `board_build.mcu` or `board_build.f_cpu`:

```ini
[env:lpmsp430fr2311]
platform = timsp430
board = lpmsp430fr2311

; change microcontroller
board_build.mcu = msp430fr2311

; change MCU frequency
board_build.f_cpu = 16000000L
```

## Debugging

The TI LaunchPad MSP-EXP430FR2311LP has an on-board debug probe: [Debugging](../../../guides/debugging/index.md) works without extra hardware.

Select the probe with the [debug_tool](../../../reference/platformio-ini/env/debug-tool.md) option in [platformio.ini](../../../reference/platformio-ini/index.md). If you do not set it, the probe marked as default is used.

:::warning

Most debug probes need a driver or udev rules. See the probe's page for instructions.

:::

| Compatible probes | On-board | Default |
|---|---|---|
| [MSP debug](../../debug-probes/mspdebug.md) | Yes | Yes |
