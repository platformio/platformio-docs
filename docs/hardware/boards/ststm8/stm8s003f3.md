# ST STM8S003F3 chip

## Hardware

Platform [ST STM8](../../platforms/ststm8.md): The STM8 is an 8-bit microcontroller family by STMicroelectronics an extended variant of the ST7 microcontroller architecture. STM8 microcontrollers are particularly low cost for a full-featured 8-bit microcontroller.

| Specification | Value |
|---|---|
| **Microcontroller** | STM8S003F3P6 |
| **Frequency** | 16MHz |
| **Flash** | 8KB |
| **RAM** | 1KB |
| **Vendor** | [ST](https://www.st.com/resource/en/datasheet/stm8s003f3.pdf?utm_source=platformio.org&utm_medium=docs) |

## Configuration

Use the board ID `stm8s003f3` in the [board](../../../reference/platformio-ini/env/board.md) option of [platformio.ini](../../../reference/platformio-ini/index.md):

```ini
[env:stm8s003f3]
platform = ststm8
board = stm8s003f3
```

To override a setting of the board manifest [stm8s003f3.json](https://github.com/platformio/platform-ststm8/blob/master/boards/stm8s003f3.json) in a project environment, use an option named `board_` followed by the setting's JSON path, for example `board_build.mcu` or `board_build.f_cpu`:

```ini
[env:stm8s003f3]
platform = ststm8
board = stm8s003f3

; change microcontroller
board_build.mcu = stm8s003f3p6

; change MCU frequency
board_build.f_cpu = 16000000L
```

## Uploading

ST STM8S003F3 chip supports these upload protocols:

- `serial`
- `stlinkv2`

The default is `stlinkv2`.

To use another one, set the [upload_protocol](../../../reference/platformio-ini/env/upload-protocol.md) option:

```ini
[env:stm8s003f3]
platform = ststm8
board = stm8s003f3

upload_protocol = stlinkv2
```

## Debugging

The ST STM8S003F3 chip has no on-board debug probe: [Debugging](../../../guides/debugging/index.md) needs one of the external probes below.

Select the probe with the [debug_tool](../../../reference/platformio-ini/env/debug-tool.md) option in [platformio.ini](../../../reference/platformio-ini/index.md). If you do not set it, the probe marked as default is used.

:::warning

Most debug probes need a driver or udev rules. See the probe's page for instructions.

:::

| Compatible probes | On-board | Default |
|---|---|---|
| [ST-LINK](../../debug-probes/stlink.md) |  | Yes |
