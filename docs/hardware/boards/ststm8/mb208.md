# sduino MB (STM8S208MBT6B)

## Hardware

Platform [ST STM8](../../platforms/ststm8.md): The STM8 is an 8-bit microcontroller family by STMicroelectronics an extended variant of the ST7 microcontroller architecture. STM8 microcontrollers are particularly low cost for a full-featured 8-bit microcontroller.

| Specification | Value |
|---|---|
| **Microcontroller** | STM8S208MBT6 |
| **Frequency** | 16MHz |
| **Flash** | 128KB |
| **RAM** | 6KB |
| **Vendor** | [sduino](https://github.com/roybaer/sduino_mb?utm_source=platformio.org&utm_medium=docs) |

## Configuration

Use the board ID `mb208` in the [board](../../../reference/platformio-ini/env/board.md) option of [platformio.ini](../../../reference/platformio-ini/index.md):

```ini
[env:mb208]
platform = ststm8
board = mb208
```

To override a setting of the board manifest [mb208.json](https://github.com/platformio/platform-ststm8/blob/master/boards/mb208.json) in a project environment, use an option named `board_` followed by the setting's JSON path, for example `board_build.mcu` or `board_build.f_cpu`:

```ini
[env:mb208]
platform = ststm8
board = mb208

; change microcontroller
board_build.mcu = stm8s208mbt6

; change MCU frequency
board_build.f_cpu = 16000000L
```

## Uploading

sduino MB (STM8S208MBT6B) supports these upload protocols:

- `serial`
- `stlinkv2`

The default is `serial`.

To use another one, set the [upload_protocol](../../../reference/platformio-ini/env/upload-protocol.md) option:

```ini
[env:mb208]
platform = ststm8
board = mb208

upload_protocol = serial
```

## Debugging

The sduino MB (STM8S208MBT6B) has no on-board debug probe: [Debugging](../../../guides/debugging/index.md) needs one of the external probes below.

Select the probe with the [debug_tool](../../../reference/platformio-ini/env/debug-tool.md) option in [platformio.ini](../../../reference/platformio-ini/index.md). If you do not set it, the probe marked as default is used.

:::warning

Most debug probes need a driver or udev rules. See the probe's page for instructions.

:::

| Compatible probes | On-board | Default |
|---|---|---|
| [ST-LINK](../../debug-probes/stlink.md) |  | Yes |
