# Configuration {#configuration}

PlatformIO Unit Testing can be configured using ["platformio.ini" (Project Configuration File)](../../reference/platformio-ini/index.md). See available options below:

- [Testing options](../../reference/platformio-ini/env/test-options.md)

  - [`test_framework`](../../reference/platformio-ini/env/test-framework.md)
  - [`test_filter`](../../reference/platformio-ini/env/test-filter.md)
  - [`test_ignore`](../../reference/platformio-ini/env/test-ignore.md)
  - [`test_port`](../../reference/platformio-ini/env/test-port.md)
  - [`test_speed`](../../reference/platformio-ini/env/test-speed.md)
  - [`test_build_src`](../../reference/platformio-ini/env/test-build-src.md)
  - [`test_testing_command`](../../reference/platformio-ini/env/test-testing-command.md)

You can also override some options using [pio test](../../reference/cli/pio-test.md) command.
