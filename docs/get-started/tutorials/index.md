## Example projects {#project-examples}

Ready-to-build projects for every development platform and framework are in
the [PlatformIO examples](https://github.com/platformio/platformio-examples)
repository. Each [platform](../../hardware/platforms/index.md) and
[framework](../../hardware/frameworks/index.md) page also links to its
examples.
