# pio team destroy {#pio-team-destroy}

## Usage {#usage}

```bash
pio team destroy ORGNAME:TEAMNAME
```

## Description {#description}

Destroy a team.

If you need to remove a user from a team, please use [pio team remove](./remove.md) command.
