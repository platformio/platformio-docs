# pio account password {#pio-account-password}

Change the password of your [PlatformIO Account](../../../get-started/platformio-account.md).

## Usage {#usage}

```bash
pio account password [OPTIONS]
```

## Options {#options}

### `--old-password` {#cmdoption-pio-account-password-old-password}

Your current password. If you omit it, the command asks for it.

### `--new-password` {#cmdoption-pio-account-password-new-password}

The new password. If you omit it, the command asks for it twice, to confirm.
