# pio account

Manage your [PlatformIO Account](../../../get-started/platformio-account.md) from the command line.

## Commands {#commands}

| Command | Description |
| --- | --- |
| [`pio account register`](./register.md) | Create an account |
| [`pio account login`](./login.md) | Sign in |
| [`pio account logout`](./logout.md) | Sign out |
| [`pio account show`](./show.md) | Show the profile, packages and subscriptions |
| [`pio account update`](./update.md) | Update the profile |
| [`pio account password`](./password.md) | Change the password |
| [`pio account forgot`](./forgot.md) | Reset a forgotten password |
| [`pio account token`](./token.md) | Get or regenerate the authentication token |
| [`pio account destroy`](./destroy.md) | Delete the account |

For the options of a command, run `pio account COMMAND --help`.
