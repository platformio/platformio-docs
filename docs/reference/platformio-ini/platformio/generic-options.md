# Generic options

General project settings.

| Option | Description |
| --- | --- |
| [`name`](./name.md) | A project name |
| [`description`](./description.md) | Describe a project with a short information |
| [`default_envs`](./default-envs.md) | Configure a list with environments which PlatformIO should process by default |
| [`extra_configs`](./extra-configs.md) | Extend main configuration with the extra configuration files |
