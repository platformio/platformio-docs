# `libdeps_dir` {#libdeps-dir}

Type: `DirPath` | Multiple: `No` | Default: "[workspace_dir](./workspace-dir.md)/libdeps"

Internal storage where [Library Management](../../../guides/libraries/index.md) will install project dependencies ([lib_deps](../env/lib-deps.md)).

This option can also be configured by the global environment variable [`PLATFORMIO_LIBDEPS_DIR`](../../environment-variables.md#envvar-PLATFORMIO_LIBDEPS_DIR).
