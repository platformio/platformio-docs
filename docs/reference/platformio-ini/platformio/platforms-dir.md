# `platforms_dir` {#platforms-dir}

Type: `DirPath` | Multiple: `No` | Default: "[core_dir](./core-dir.md)/platforms"

Global storage where **PlatformIO Package Manager** installs [Development Platforms](../../../hardware/platforms/index.md).

This option can also be configured by the global environment variable [`PLATFORMIO_PLATFORMS_DIR`](../../environment-variables.md#envvar-PLATFORMIO_PLATFORMS_DIR).
