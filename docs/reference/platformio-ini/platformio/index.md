# Section `[platformio]` {#section-platformio}

The `[platformio]` section holds project-wide settings: the project name, the
environments processed by default, extra configuration files, and the
locations of PlatformIO data and project folders.

All options are optional.

| Group | Options |
| --- | --- |
| [Generic options](./generic-options.md) | `name`, `description`, `default_envs`, `extra_configs` |
| [Directory options](./directory-options.md) | `core_dir`, `globallib_dir`, `platforms_dir`, `packages_dir`, `cache_dir`, `build_cache_dir`, `workspace_dir`, `build_dir`, `libdeps_dir`, `include_dir`, `src_dir`, `lib_dir`, `data_dir`, `test_dir`, `boards_dir`, `monitor_dir`, `shared_dir` |
